# QA Run Logs

Use this directory for QA run summaries and references to long logs.

- Save raw long logs as `.log` files when needed; `.gitignore` ignores `*.log`.
- Commit only concise summaries when they are useful for future regression work.
- Do not include secrets, cookies, API keys, tokens, database URLs, or passwords.
- Reports should include command, scope, result, key failure lines, and log path.
